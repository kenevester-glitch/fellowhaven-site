# fellowhaven.com

The one-page FellowHaven website, served free by GitHub Pages at https://fellowhaven.com.

- `index.html`, `privacy.html`, `terms.html`, `delete-account.html` and `404.html` are generated by `build.py`.
- The Privacy Policy, Terms of Use and delete-account text live in the app repo (`docs/legal/*.md`). After editing them there, run `python3 build.py path/to/fellowhaven-app/docs/legal`, then commit and push.
- No trackers, analytics, cookies or outside requests.
